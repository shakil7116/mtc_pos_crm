# Archives

Session logs, phase test reports and bug audits from the build-out (Jul 2026).
Kept for history — **not** current documentation. Nothing here is maintained.

For what is true now, read [CLAUDE.md](../CLAUDE.md), [connections.md](../connections.md)
and [decisions/log.md](../decisions/log.md).

Be careful trusting anything here: `BUGS.md` and the `*_LOG.md` files describe
defects that have since been fixed, and several describe systems that were later
removed (the pick queue, the standalone return-voucher pages, the day-off payroll
deduction). Treat them as a record of what happened, not a description of the app.
